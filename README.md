# Архивариус странных вещей

Небольшой творческий офлайн-агент на Python. Напиши название обычного предмета — агент создаст его фантастическое досье: происхождение, необычную способность, странную цену и сюжетную миссию.

## Примеры заданий для агента

- «Преврати старый ключ в артефакт для фэнтези».
- «Сделай из варежки загадочный предмет в жанре мистики».

## Выбери один из жанров

1. Фэнтези.
2. Научная фантастика.
3. Мистика.

## Как запустить на компьютере

1. Установи Python 3.
2. Скачай файлы проекта в одну папку.
3. Открой терминал в этой папке.
4. Запусти:

   ```bash
   python main.py
   ```

   На некоторых системах команда может быть `python3 main.py`.

Дополнительные библиотеки и API-ключи не нужны.

## Как запустить через GitHub Codespaces

1. Загрузить файлы в GitHub-репозиторий.
2. Открыть репозиторий → **Code → Codespaces → Create codespace**.
3. В Codespaces открыть **Terminal → New Terminal**.
4. Ввести `python main.py`.

## Файлы проекта

- `main.py` — спрашивает предмет и запускает диалог.
- `agent.py` — собирает текст досье.
- `world_data.py` — хранит жанры и сюжетные заготовки.

## Важно

Это **офлайн-агент на правилах и шаблонах**, а не подключённая генеративная нейросеть. Он работает без интернета и не отправляет введённый текст на внешние сервисы. Чтобы получить ответы, которые модель сочиняет свободно, понадобится отдельно подключить языковую модель через API.
